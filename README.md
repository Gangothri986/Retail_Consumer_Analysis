# 🛍️ Retail Consumer Analytics

An end-to-end data analytics project that analyzes customer shopping behavior to uncover insights related to purchasing patterns, product performance, discounts, customer loyalty, subscriptions, and revenue.

---

## 📌 Project Overview

Retail Consumer Analytics is an end-to-end data analytics project built using **Python, SQL Server, and Power BI**.

The project follows a complete analytics workflow:

**Raw Dataset → Python Data Preprocessing → SQL Server → SQL Business Analysis → Power BI Dashboard → Business Insights**

The objective is to transform raw customer shopping data into meaningful insights that can support business and marketing decisions.

---

## 🎯 Business Objectives

The project focuses on understanding:

- Customer purchasing behavior
- Product performance

- Discount usage

## 🔄 Project Workflow

### 1. Data Collection
The raw customer shopping behavior dataset is stored as a CSV file.

### 2. Data Preprocessing
Python and Pandas are used to:
- Explore the dataset
- Handle missing values
- Standardize column names
- Create age groups
- Convert purchase frequency into days
- Perform data consistency checks

### 3. SQL Server
The processed data is loaded into Microsoft SQL Server for structured storage and analysis.

### 4. SQL Business Analysis
SQL queries are used to answer business questions related to:
- Revenue
- Customer spending
- Product performance
- Discounts
- Subscriptions
- Customer loyalty
- Age groups

### 5. Power BI Dashboard
Power BI is used to visualize the analyzed data and present business insights.

---

## 📊 SQL Analysis

The project answers the following business questions:

1. What is the total revenue generated by male and female customers?
2. Which customers used a discount but still spent more than the average purchase amount?
3. Which are the top 5 products with the highest average review rating?
4. How does the average purchase amount compare between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which 5 products have the highest percentage of discounted purchases?
7. How many customers fall into New, Returning, and Loyal segments?
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?
